# 🏥 МедОнлайн - учебное веб-приложение с уязвимостями

Демонстрационное веб-приложение «Личный кабинет для онлайн-записи к врачу»,
созданное **исключительно в образовательных целях** для демонстрации трёх
классических веб-уязвимостей.

> ⚠️ **ВНИМАНИЕ!** Приложение содержит намеренно внедрённые уязвимости.
> Никогда не используйте этот код в реальных проектах. Запускайте только
> локально (127.0.0.1), не выставляйте в интернет.

---

## 📋 О приложении

**МедОнлайн** - личный кабинет пациента, в котором можно:

- Зарегистрироваться и войти в систему
- Просматривать свои записи к врачам с диагнозами и назначениями
- Искать врачей по ФИО или специальности
- Редактировать контактные данные (телефон, email)
- Записываться на приём

Стек: **Python 3 + Flask + SQLite**. Никаких внешних зависимостей,
кроме Flask - специально, чтобы всё было максимально наглядно.

```bash

# 4. Открыть в браузере
